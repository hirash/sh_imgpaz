# しゃしんパズル ✨（iPad向け 知育パズルゲーム）

6さいの女の子向けに作った、ファンシーでかわいい写真パズルです。
取り込んだ写真（またはアプリ内蔵のかわいい絵）を、台紙の区切り線に合わせてピースをはめて遊びます。

## あそびかた

1. iPadの **Safari** で `index.html` を開く（下記「使い方」参照）
2. 「はじめる」→ 写真をえらぶ
   - 内蔵のかわいい絵（🌈 にじ / 🐱 ねこ / 🌷 おはな / 🎂 ケーキ）から選ぶ
   - または「📷 しゃしんを とる・えらぶ」でカメラ撮影 or 写真ライブラリから選ぶ
3. レベルをえらぶ
4. トレイのピースを台紙の区切り線に **ドラッグ** してはめる
5. ぜんぶはまると おいわい 🏆

## レベルと知育のねらい

| レベル | 内容 | ねらい |
|--------|------|--------|
| 🟦 とても かんたん | しかく 4こ（2×2） | 位置あわせ・かたちの認識 |
| 🟪 かんたん | しかく 9こ（3×3） | 少し多いピースへの挑戦 |
| 🔺 さんかく | 三角 8こ（2×2） | **三角ふたつで四角になる** ことを学ぶ |
| 🔄 まわして | しかく 9こ・回転あり | **むきを合わせて回す** 空間認識 |
| 🔺🔄 さんかく＆まわす | 三角 8こ・回転あり | 三角＋回転の総合 |

- 回転レベルでは、ピースを **タップ** すると90°ずつ回ります。むきが合うとカチッとはまります。
- 「👀 おてほん」ボタンで、台紙にうっすら完成図を表示／非表示できます（小さい子のヒント）。
- 「🔀 もういちど」で同じレベルをシャッフルしてやり直せます。

## 特長

- **単一HTMLファイル・完全オフライン** … 外部ライブラリ・画像・音声ファイルは一切なし
- 効果音は Web Audio でその場生成（ファイル不要）
- パステルカラー・丸ゴシック・きらきら/紙吹雪演出でファンシーに
- タッチ操作（ドラッグ／タップ回転）に最適化。iPadの縦・横どちらにも対応

## 使い方（iPadで開く）

いちばん簡単なのは、`index.html` を iPad にコピーしてSafariで開く方法です。

- iCloud Drive / メール添付 / AirDrop などで `index.html` をiPadに送る
- ファイルアプリからタップして Safari で開く
- Safariの共有メニュー →「ホーム画面に追加」でアプリのように起動できます（全画面表示）

PCで動作確認する場合は、このフォルダで簡易サーバーを立てても開けます:

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
